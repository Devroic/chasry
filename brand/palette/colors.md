# Chasry — Brand Palette

| Ρόλος                  | Hex       | Χρήση                                                    |
| ------------------------ | --------- | ----------------------------------------------------------- |
| Primary — Navy          | `#23458D` | CTA κουμπιά, links, headers, βασικό brand χρώμα            |
| Primary Hover           | `#0B2561` | Hover/active state primary κουμπιών                        |
| Primary Tint            | `#E2E9F8` | Ανοιχτό background για sections/cards                       |
| Secondary — Sky Blue    | `#63C2EE` | Accents, highlights, δεύτερα κουμπιά, illustrations         |
| Secondary Hover         | `#2CADE8` | Hover/active state secondary κουμπιών                      |
| Secondary Tint          | `#B8E3F7` | Ανοιχτό γαλάζιο background/accent panels                    |
| Ink (κείμενο)           | `#0D0D0D` | Βασικό χρώμα κειμένου                                       |
| Neutral gray            | `#94A3B8` | Borders, muted κείμενο, placeholders                        |
| Background              | `#FFFFFF` | Βασικό background                                           |

Και τα δύο βασικά χρώματα (navy, sky blue) προέρχονται από το ίδιο το icon/logo (κοστούμι/καπέλο
του χαρακτήρα). Το πράσινο (μετρητά) και ο χρυσός (κορδέλα) που υπάρχουν μέσα στο icon artwork
δεν αποτελούν μέρος του επίσημου palette — δεν χρησιμοποιούνται αλλού στο UI/site.

Machine-readable εκδοχή: `tokens.css`.
